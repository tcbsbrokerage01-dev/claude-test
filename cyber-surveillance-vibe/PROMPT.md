# 賽博監控儀 × Vibe Coding — Prompt 包

這些 prompt 和 `index.html` CH04 區塊裡的內容一致。貼到 Claude、Cursor、v0、Lovable、Bolt 等 AI 寫程式工具都可以用；如果工具支援上傳圖片，把參考圖一起附上，風格會更接近。

### 1. 完整網站 Prompt（重做這一頁）

```text
你是一位擅長互動網頁、Canvas 動畫與視覺設計的前端工程師。

請用單一 HTML 檔（CSS 和 JavaScript 都寫在檔案裡，不使用框架）做一個介紹「Vibe Coding」的單頁網站。主題是「賽博監控儀 Cyber Surveillance Cam」：整個網站看起來像監控室的螢幕牆，AI 寫程式的過程被監視器拍下來、被偵測框追蹤。介面文字用繁體中文，HUD 標籤用英文大寫。

【視覺風格】
- 背景接近黑色、帶一點綠（#060908），主要文字用磷光白綠（#d3e4da）。
- 追蹤框用螢光綠 #4dff7c，鎖定目標用警示紅 #ff3b4a，警告用琥珀黃 #ffb02e。
- 偵測框樣式：1px 細線框＋四角加粗的括號，左上角貼一個實心標籤，例如「ID 23 · 0.91」。
- 全頁覆蓋細掃描線和會閃動的顆粒雜訊（pointer-events: none）。
- 字體：標籤與數據用 IBM Plex Mono，時間戳用點陣字 Doto，中文大標用 Noto Serif TC，英文副標用 Instrument Serif 斜體，內文用 Noto Sans TC。做出「監控數據 × 時裝雜誌」的對比感。

【版面與區塊】
1. 頂部固定狀態列：閃爍的紅點 REC、品牌名、每秒更新的時間戳、SYSTEM: ONLINE；導覽做成頻道切換 CH01–CH04。
2. CH01 主畫面：左邊大標題「你負責描述，AI 負責寫。」（「描述」和「AI」各用一個偵測框框起來）、說明文字、兩個按鈕，下面有一個「PROMPT LOG」小視窗逐字打出示範 prompt。右邊是用 Canvas 即時繪製的俯視斑馬線監視畫面：十幾個行人走過，攝影機跟著主角移動，走得快的人有殘影；主角被紅框鎖定，標籤寫 SUBJECT_07 / VIBE CODER / CONF 0.982，右上角有一個放大 2.5 倍的特寫小窗，用虛線連到紅框；部分路人有綠色小框和 ID。畫面四角放 REC、CAM 編號、ISO 800、時間戳。
3. CH02 偵測流程：描述 → 生成 → 監看 → 修正 四張步驟卡；滑鼠移上去時，四角追蹤框從外往內收合並出現 LOCKED 標籤。下方一條紅色警示條，說明 vibe coding 的限制。
4. CH03 監視牆：2×2 的小監視畫面，每格用 Canvas 動畫呈現一種可以用 vibe coding 做出來的東西（落地頁、儀表板、打磚塊小遊戲、番茄鐘工具）正在被生成，並用偵測框標出元件（NAV、HERO、CTA、KPI⋯）。每格下面附一句範例 prompt 和複製按鈕。
5. CH04 Prompt 解剖：用分頁切換三種 prompt（完整網站、風格套用、修正回報），每一段用不同顏色的偵測框標註類別，旁邊是類別圖例；附複製按鈕。
6. 頁尾註明：所有監視畫面都是瀏覽器即時繪製的動畫，不是真實影像。

【動態】
- 監視畫面用 24fps 更新，模擬監控器的頓感，並有一條緩慢下移的亮帶。
- 桌機版滑鼠位置顯示十字準線和 X/Y 座標。
- 畫面不在視窗內時暫停動畫（IntersectionObserver）。
- 開啟 prefers-reduced-motion 時，所有動畫停止，只顯示靜態畫面。

【技術限制】
- 手機寬度 390px 也要正常，不能出現橫向捲動；手機版監視畫面改成直式比例。
- Canvas 要依 devicePixelRatio 處理高解析度螢幕。
- 不使用任何外部圖片或影片，所有畫面都用 Canvas 或 CSS 畫出來。
- 複製按鈕用 navigator.clipboard，失敗時退回選取文字。
```

### 2. 風格套用 Prompt（把現有網站改成監控風）

```text
請把我現有的網站改成「賽博監控儀」風格。內容、文案和功能都不要改，只動視覺。

- 深色背景（#060908）配磷光白綠文字（#d3e4da）。
- 重點元素外面加 CCTV 偵測框：1px 細線框、四角加粗括號、左上角貼實心標籤（例如「TARGET_01 · 0.97」）。一般元素用綠色 #4dff7c，最重要的一個用紅色 #ff3b4a。
- 圖片外圍加監視器 HUD：● REC、CAM 編號、每秒更新的時間戳、ISO 數值。
- 標籤用等寬字（IBM Plex Mono），大標用襯線中文字體（Noto Serif TC）。

- 全頁加掃描線和顆粒雜訊覆蓋層。
- 滑鼠移到卡片上時，追蹤框從外往內收合，並顯示 LOCKED。

- 覆蓋層要 pointer-events: none，不能擋到點擊。
- 尊重 prefers-reduced-motion。
- 文字對比要夠，掃描線不能讓內文變難讀。
```

### 3. 修正回報範例（第二輪以後用）

回報問題的格式：位置＋現象＋期望結果。

- 手機版（寬 390px）時，CH01 的大標題被監視畫面蓋住，請改成上下排列，標題在上。
- 監視畫面裡的綠色追蹤框太粗太亮，搶走主角的注意力，線寬改 1px、透明度 70%。
- 斑馬線上的行人走路速度都一樣，看起來像機器人，讓每個人的速度在 0.6 到 1.4 倍之間隨機。
- 頂部時間戳每秒跳動時寬度會變，旁邊的字跟著抖，請改用等寬數字。

### 4. 一句話範例 Prompt（CH03 監視牆）

- **落地頁**：幫我做一個咖啡豆訂閱服務的單頁網站：深色背景、大標題、三個方案的價格卡、底部常見問題摺疊選單。手機版也要好看，不要用外部圖片。
- **儀表板**：做一個個人記帳儀表板：上方四個數字卡（本月支出、儲蓄率、交易筆數、平均單筆），中間是 12 個月的支出折線圖，右邊是分類長條圖。先用假資料，資料寫在檔案開頭方便我改。
- **小遊戲**：用單一 HTML 檔做一個打磚塊遊戲：滑鼠或方向鍵控制板子、三條命、最高分存在瀏覽器裡，配色用黑底霓虹綠。手機可以用手指拖曳。
- **小工具**：做一個番茄鐘待辦清單：可以新增、勾選、刪除任務；每個任務都能開始 25 分鐘倒數，時間到畫面閃紅光提醒。資料存在瀏覽器，重新整理不會消失。
