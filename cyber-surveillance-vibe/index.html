CH01 · Case file 03 · Vibe coding

Cyber Surveillance Cam

你負責描述，
AI 負責寫。

Vibe coding 是用自然語言寫程式：你描述想要的畫面和行為，AI 產生程式碼，你看結果、再修正描述，直到它長成你要的樣子。這一頁也是這樣做出來的，頁面上的監視畫面不是影片，是瀏覽器即時畫出來的。

    CH02

    偵測流程

    Detection pipeline

    Vibe coding 是一個迴圈。不需要一次就說對，但每一圈都要比上一圈說得更具體。

    1. Step 01Describe

      描述Describe

      用白話說清楚要做什麼、給誰用、長什麼樣子。附一張參考圖，通常比三段形容詞有用。

      Input → 文字＋參考圖

    2. Step 02Generate

      生成Generate

      AI 寫出 HTML、CSS、JavaScript，或整個專案。第一版不必完美，重點是先有東西可以看。

      Output → 可執行的程式碼

    3. Step 03Observe

      監看Observe

      打開預覽，用電腦和手機各看一次。像盯監視器一樣找問題：哪裡跑版、哪裡太慢、哪裡不像你要的。

      Check → 桌機＋手機

    4. Step 04Refine

      修正Refine

      把看到的問題具體回報。「手機版標題被切掉」比「怪怪的」好修得多。改完回到 Step 01。

      Loop → 回到 Step 01

    Alert 02-A · 已知盲區

    Vibe coding 很適合做原型、個人工具和視覺實驗。要正式上線，或是處理登入、金流、個人資料時，還是需要有人看懂並檢查 AI 寫的程式碼，因為它可能寫出看起來正常、實際上有漏洞的程式。

    監視牆

    Monitor wall

    四個頻道，四種用一段話就能做出第一版的東西。畫面裡的線框是示意動畫，下面的 prompt 可以直接拿去用。

    CAM-02 · LandingTRK
    Scene 1/4

    落地頁Landing page

    幫我做一個咖啡豆訂閱服務的單頁網站：深色背景、大標題、三個方案的價格卡、底部常見問題摺疊選單。手機版也要好看，不要用外部圖片。

    One-line prompt
    CAM-03 · DashboardTRK
    Scene 2/4

    儀表板Dashboard

    做一個個人記帳儀表板：上方四個數字卡（本月支出、儲蓄率、交易筆數、平均單筆），中間是 12 個月的支出折線圖，右邊是分類長條圖。先用假資料，資料寫在檔案開頭方便我改。

    One-line prompt
    CAM-04 · GameTRK
    Scene 3/4

    小遊戲Mini game

    用單一 HTML 檔做一個打磚塊遊戲：滑鼠或方向鍵控制板子、三條命、最高分存在瀏覽器裡，配色用黑底霓虹綠。手機可以用手指拖曳。

    One-line prompt
    CAM-05 · ToolTRK
    Scene 4/4

    小工具Utility

    做一個番茄鐘待辦清單：可以新增、勾選、刪除任務；每個任務都能開始 25 分鐘倒數，時間到畫面閃紅光提醒。資料存在瀏覽器，重新整理不會消失。

    One-line prompt
