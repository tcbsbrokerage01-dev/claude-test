# Wavefield：Vibe Coding Prompt

下面是用來生成這個網站的 prompt，可直接貼進 Claude、Cursor、v0、Bolt、Lovable 等工具。若工具支援附圖，連同參考圖一起附上效果最好。

---

## 完整版

```
請幫我做一個「音頻可視化」單頁網站，叫 WAVEFIELD。風格是黑底、白色點陣、有未來科技感的儀器介面。

【視覺方向】
- 參考畫面：黑色背景上，無數白色短點堆疊成垂直柱狀波形，以水平中線上下對稱展開，像聲紋或示波器的磷光殘影；點排成整齊的橫列。底部有一行很小的等寬字讀數。
- 只用單色：近黑 #040506 和冷白 #EEF2F3，靠透明度做層次。不要紫藍漸層，也不要霓虹綠。
- 字體：數據和標籤用 Martian Mono（大寫、字距 0.14em），中文用 Noto Sans TC。
- 介面像儀器前面板：1px 細線、畫面四角的 L 形框角、很淡的掃描線和暗角。按鈕是直角、透明底，選中時黑白反轉。

【技術限制】
- 只有一個 index.html，純 HTML/CSS/JS，不用框架，不用建置工具。
- 繪圖用 Canvas 2D（devicePixelRatio 上限 2），音訊用 Web Audio API 的 AnalyserNode（fftSize 2048）。
- 效能：點按透明度分成 10 組，每組只做一次 beginPath + rect + fill。柱狀圖先畫成 5 段實心長條（越往上越透明），再蓋上一層「每 3px 留 1px」的橫列遮罩 pattern，把長條切成點，避免每幀畫幾萬個點。

【音源】
1. 一打開就跑「模擬訊號」預覽，不需要聲音，畫面不能是空的。開頁前先預跑約 7 秒，讓波形一開始就是滿的。狀態要明確標示 PREVIEW · 模擬訊號。
2. DEMO：用 Web Audio 即時合成一段 118 BPM 的電子 loop，包含 kick、clap、hi-hat、鋸齒波 bass、和弦 pad、方波琶音加 delay，和弦進行 Am–F–C–G。不載入任何外部音檔，用 look-ahead 排程器。
3. FILE：上傳或拖放音檔（MP3/WAV/M4A/OGG/FLAC），用 decodeAudioData 解碼後循環播放。
4. MIC：getUserMedia 麥克風，關閉 echoCancellation / noiseSuppression / autoGainControl，不回送到喇叭以免回授。被拒絕時顯示清楚的中文說明。

【四種可視化模式，鍵盤 1–4 切換】
1. WAVEFIELD（主視覺，最像參考圖）：每秒 60 欄、由右往左捲動的歷史紀錄。每欄從中線往上、往下長出點柱，上半高度偏向中高頻能量，下半偏向低頻能量。用 RMS 包絡加慢速自動增益做正規化，每欄加一點隨機起伏形成鋸齒感，越舊的欄越暗，柱頂外散落幾顆位置固定的雜點。底部標 −1s、−2s… 和 NOW。
2. SPECTRUM：30 Hz–16 kHz 對數頻率的點陣柱，下方有較暗的倒影，柱頂有緩慢下落的峰值保持點，底部標 50/100/200/500/1k/2k/5k/10k Hz。低頻比 FFT bin 還窄的頻帶用線性插值，避免出現階梯。
3. SCOPE：示波器，用零交越觸發讓波形穩定，10×8 點陣格線，標示 ms/div 和 FS/div（數值要依取樣率和 gain 算出來）。
4. RADIAL：環狀頻譜，左右鏡像，上方低頻、下方高頻；內圈是時域波形點環，外圈是每 6° 一格的刻度。

【HUD 與控制】
- 頂部：品牌字 WAVEFIELD 和中文副標「音場 · 即時音頻可視化」；右側是狀態晶片（PREVIEW / LIVE / PAUSED，帶閃爍方點）、時間碼 T+mm:ss.cc（音檔模式顯示 目前 / 總長）、FPS、全螢幕按鈕。
- 畫面上方說明目前模式的座標軸意義。
- 底部控制列：DEMO / FILE / MIC、播放/暫停、四個模式按鈕、GAIN（0.4–2.5×）和 TRAIL 殘影（0–85%）滑桿。
- 最底一行即時讀數：SRC、FFT、SR 取樣率、RMS（dBFS）、PEAK 峰值頻率、CENTROID 頻譜質心、BPM≈。BPM 用低頻 spectral flux 偵測 onset，取間隔中位數，折算到 80–170 之間。旁邊放 L/M/H 三段電平條和節拍閃燈。
- 快捷鍵：空白鍵播放/暫停、1–4 切換模式、F 全螢幕。

【品質要求】
- 手機 390px 寬也要好用：控制列換行，模式按鈕排成 4 欄網格，頁面不能橫向捲動。
- 支援 prefers-reduced-motion：關掉閃爍和節拍閃燈。
- 所有按鈕都能用鍵盤操作，focus 樣式要清楚。
- 讀數必須是真的量測值；模擬預覽時取樣率顯示 SIM，不要假裝是真實音訊。
```

## 精簡版（想讓 AI 自由發揮時用）

```
做一個單檔 index.html 的音頻可視化網站：黑底、白色點陣、未來儀器感。主畫面是由短點堆疊、以中線上下對稱、由右往左捲動的聲紋柱（像示波器磷光殘影）。用 Web Audio + Canvas 2D，支援內建合成示範音軌、上傳音檔、麥克風；另外做頻譜、示波器、環狀頻譜三種模式。底部用小等寬字顯示 RMS dBFS、峰值頻率、BPM 等真實讀數。純單色，不要漸層和霓虹色，手機也要能用。
```
