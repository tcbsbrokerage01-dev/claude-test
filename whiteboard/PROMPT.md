# 貼貼白板：Vibe Coding Prompt

把下面整段貼進 Claude、Lovable、Bolt、v0 或 Cursor 等工具即可。成品參考：同資料夾的 `index.html`。

```text
請幫我做一個單頁網站「貼貼白板 Sticky & Sketch Board」：一個像實體白板的互動頁面，使用者可以貼便利貼、用畫筆塗鴉、蓋貼紙。整頁固定在一個螢幕內，不能上下捲動。

【技術】
- 單一 HTML 檔（HTML + CSS + 原生 JavaScript），不用框架；字體從 Google Fonts 載入。
- 塗鴉畫在 <canvas> 上（要處理 devicePixelRatio，避免模糊）；便利貼和貼紙用 DOM 元素疊在白板上。
- 全部用 Pointer Events，滑鼠、手機觸控、觸控筆都要能用。
- 白板內容存在 localStorage，重新整理後還在。

【版面】
- html、body 高度 100%、overflow hidden，不能出現捲軸。
- 背景是淡灰色牆面 #e6e9e8，中間一塊白板填滿剩下空間，四周留 16px；白板圓角 22px、6px 淺色外框、柔和陰影，底色 #fbfbf9，加上間距 22px 的點點格線。
- 白板上方是頁首（在牆面上，不壓到白板）：
  - 左邊品牌標：2px 點點虛線圓角框，裡面是灰色膠帶底的英文斜體「Sticky & Sketch Board」（Newsreader Italic），旁邊是粗襯線中文「貼貼白板」（Noto Serif TC 900），框的右上角有一個 8px 黑色小方塊。
  - 右邊：自動儲存狀態文字、「復原」「重做」「清空」三個按鈕（線條 SVG 圖示 + 文字）。
- 桌機：工具列直立浮在白板左側中間；選了有選項的工具，旁邊出現選項面板（顏色、粗細）。滑過工具按鈕顯示提示「畫筆 P」。
- 手機（寬度 640px 以下）：工具列改成橫的，浮在白板底部中間，選項面板在它上方；按鈕只留圖示。
- 白板右下角放一條像標籤機打字的紙膠帶提示：黑底打字字標籤（Special Elite）顯示 PEN / NOTE 等，後面接中文用法說明，跟著目前工具變。

【工具】（括號內是快捷鍵）
1. 移動（V）：拖曳便利貼上方的紙膠帶來移動；點選便利貼或貼紙後按 Delete 刪除；雙擊白板空白處新增便利貼。
2. 便利貼（N）：點白板任一處貼上新便利貼並直接進入輸入，貼完自動切回移動工具。5 種顏色：奶油黃 #fbe57d、櫻花粉 #f8c6d3、薄荷綠 #a3dccf、薰衣草 #d9d1f4、晴空藍 #c6def4。選取中的便利貼點顏色會直接換色。
3. 畫筆（P）：5 色（墨黑 #262827、青綠 #2e9c8d、玫瑰 #e0607e、鈷藍 #3f6fd1、橘子 #ef8a3c），3 種粗細；線條用二次貝茲曲線連中點，畫起來要平滑。
4. 螢光筆（H）：透明度約 42%，3 色（檸檬黃、蜜桃粉、薄荷綠）、2 種粗細。canvas 疊在便利貼上方並設 mix-blend-mode: multiply，畫在便利貼上要像真的螢光筆。
5. 橡皮擦（E）：滑過的線條整筆擦掉，游標變成一個圓圈；快速移動時也不能漏擦。
6. 貼紙（S）：星星（珠光漸層）、小花（白色花瓣 + 黑色手繪線 + 黃色花心）、愛心、打勾、粉色條紋紙膠帶；點一下就蓋上，可以連續蓋，貼紙可拖曳、選取後可刪除。

【便利貼細節】
- 頂部中間貼一小段半透明灰色條紋紙膠帶（兩端鋸齒，用 clip-path），整條頂部 28px 是拖曳把手。
- 每張隨機微微旋轉 -2.5° 到 2.5°；拖曳時轉正、放大 1.03、陰影加深，像被拿起來。
- 內文用 textarea，透明背景，字體 LXGW WenKai TC（手寫感），桌機 17px、手機 15px，placeholder「寫點什麼…」。
- 右下角折角是調整大小的把手（最小 120×96、最大 440×440）。
- 右上角有「換顏色」小圓點（顯示下一個顏色）和「刪除」×，滑鼠移上或選取時才出現；觸控裝置一直顯示。
- 新增便利貼和貼紙時有小小的彈出動畫；要尊重 prefers-reduced-motion。
- 拖曳和縮放都不能超出白板範圍；視窗縮放時重算 canvas 尺寸並重畫，便利貼也要夾回白板內。

【其他功能】
- 復原 / 重做：Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（Ctrl+Y 也可以）。用整個白板狀態的 JSON 快照實作，最多保留 100 步；打字停 0.7 秒才記成一步。正在打字時，快捷鍵交給 textarea 自己處理。
- 清空：先在按鈕下方跳出頁面內的確認小卡（不要用 alert/confirm），寫「清空整個白板？便利貼、貼紙和塗鴉都會移除。清空後還可以按『復原』找回來。」清空後底部出現提示「白板已清空」並附「復原」按鈕。刪除單張便利貼或貼紙也有同樣的提示。
- 第一次打開不要是空白，預先放好範例：5 張便利貼（「雙擊白板空白處就能貼一張便利貼」「抓住上面的紙膠帶可以拖曳移動」「用畫筆或螢光筆直接在板子上塗鴉」「週末市集清單：野餐墊、底片相機、零錢包」「秋天配色靈感：奶茶 × 楓葉橘 × 灰綠」），加上一個手繪箭頭、一個圈住便利貼的紅圈、一筆螢光筆、一條波浪底線，以及星星、小花、愛心貼紙。
- 所有介面文字用繁體中文；每個按鈕都要有 aria-label，鍵盤操作要有清楚的 focus 樣式。

【風格關鍵字】
韓系文具、小紅書手帳風、淡灰白色調、紙膠帶、標籤機打字字、珠光星星貼紙、手繪小花。避免紫藍漸層，也不要用 emoji 當圖示；圖示一律用 1.8px 線條的 SVG。
```

## 想做成多人即時協作的話

上面的版本只存在使用者自己的瀏覽器裡。若要像 Miro 一樣多人同時編輯，需要後端同步，可以在 prompt 最後再加一句：

```text
加上多人即時協作：用 Supabase Realtime（或 Liveblocks / Yjs）同步 items 和 strokes，顯示其他人的游標和名字，並有一個「分享連結」按鈕。
```
